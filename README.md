## 📌 About The Project

**BiteBox** is a responsive food ordering web application that provides users with an interactive platform to explore food items, manage their cart and experience a convenient ordering process.

The project focuses on creating a smooth user experience through an organized interface, dynamic functionality and practical food-ordering features.

## ✨ Key Features

- 🍕 **Food Menu:** Browse available food items.
- 🛒 **Shopping Cart:** Add, remove and manage cart items.
- 💰 **Dynamic Pricing:** Automatic price calculations and discount functionality.
- 📦 **Order Management:** Explore the ordering experience and order-related pages.
- 👤 **User Accounts:** Login, signup and account-related pages.
- 📱 **Responsive Design:** User-friendly layouts across different screen sizes.
- 🎨 **Interactive Interface:** Smooth navigation and engaging visual elements.

## 🚀 Getting Started

Follow these steps to run the project locally.

**1. Clone the repository**

```bash
git clone https://github.com/sarvadaanvekar17-bit/bitebox.git
```

**2. Open the project folder**

```bash
cd bitebox
```

**3. Run the application**

Open `index.html` in your browser or use the VS Code Live Server extension.

Check the backend folder's instructions separately if you want to run its services.
